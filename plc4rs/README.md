# PLC4RS - Apache PLC4X for Rust

This is the Rust implementation of the Apache PLC4X project, providing a library for industrial communication with PLCs.

## Features

- Transport layer with TCP and UDP implementations
- S7 protocol implementation
- Async I/O with Tokio
- Memory-safe implementation with no unsafe code

## Usage

See the examples directory for usage examples.

## Building

### Prerequisites

- Rust 1.75.0 or newer
- Cargo

### Building with Cargo

```bash
cargo build
```

### Building with Maven

```bash
mvn -Pwith-rust clean install
```
